### **Epic: UI 텍스트 한글화 및 가독성 개선**

**목표:** 앱 내 모든 텍스트를 한국 사용자에게 친숙하고 자연스러운 표현으로 변경하여 사용성을 높입니다.

**Task 1: 로그인 화면 한글화**

-   [ ] Subtask: `LoginScreen`의 환영 메시지, 필드 레이블, 버튼 텍스트를 자연스러운 한국어로 변경. (예: 'Welcome Back' -> '다시 오셨네요!', 'Sign Up' -> '회원가입')
-   [ ] Subtask: **(테스트)** 변경된 한국어 텍스트를 기준으로 `login_screen_test.dart` 위젯 테스트 수정.

**Task 2: 회원가입 화면 한글화**

-   [ ] Subtask: `SignUpScreen`의 제목, 필드 레이블, 버튼 텍스트, 상태 메시지를 모두 한국어로 변경. (예: 'Confirm Password' -> '비밀번호 확인', 'Check' -> '중복 확인')
-   [ ] Subtask: **(테스트)** 변경된 한국어 텍스트를 기준으로 `sign_up_screen_test.dart` 위젯 테스트 수정.

**Task 3: 알림 및 에러 메시지 한글화**

-   [ ] Subtask: `SignUpViewModel`에서 발생시키는 유효성 검사 에러 메시지를 모두 한국어로 변경. (예: 'Passwords do not match' -> '비밀번호가 일치하지 않습니다.')
-   [ ] Subtask: `CustomAlertDialog`를 통해 표시되는 모든 성공/실패/확인 메시지를 한국어로 변경.
-   [ ] Subtask: **(테스트)** 변경된 한국어 에러 메시지를 검증하도록 `sign_up_viewmodel_test.dart` 단위 테스트 수정.

**Task 4: 최종 검증**

-   [ ] Subtask: 전체 테스트(`flutter test`)를 실행하여 한글화 작업이 기존 기능에 영향을 주지 않았는지 확인.
-   [ ] Subtask: 앱을 실행하여 모든 화면의 텍스트가 자연스러운 한국어로 표시되는지 시각적으로 검증.
