### **Epic: 핵심 UX 강화 및 로그인 경험 고도화**

**목표:** 자동 로그인, 키보드 액션 등 필수적인 UX 기능을 구현하고, 한국 사용자 환경에 최적화된 폰트를 적용하여 애플리케이션의 완성도를 높입니다.

**Task 1: 로그인 API 재검증 및 기본 환경 개선**

-   [x] Subtask: `curl`을 통해 `/auth/login` API 명세를 다시 한번 명확히 확인하여, 현재 구현(요청 방식, 본문, 응답)이 명세와 100% 일치하는지 교차 검증.
-   [x] Subtask: (필요시) 검증 결과에 따라 `AuthRepositoryImpl`의 `login` 메소드 및 관련 테스트 코드 수정.
-   [x] Subtask: `google_fonts` 패키지를 추가하고, 한국 웹 환경에서 선호도가 높은 'Noto Sans KR' 폰트를 `AppTheme`에 적용하여 앱 전반의 가독성 향상.

**Task 1A: 에셋 로딩 경로 오류 수정**
-   [ ] Subtask: `main.dart`에서 `dotenv.load()` 호출 시, 파일 경로에서 중복된 `assets/` 부분을 제거.
-   [ ] Subtask: **(테스트)** `flutter test`를 다시 실행하여, 에셋 로딩과 관련된 오류 없이 모든 테스트가 통과하는지 확인.
-   [ ] Subtask: **(검증)** `flutter run`을 통해 앱이 정상적으로 실행되고, 환경 변수를 올바르게 읽어오는지 확인.

**Task 2: 키보드를 이용한 로그인 기능 구현**
-   [ ] Subtask: `LoginScreen`의 이메일, 비밀번호 필드를 `Form` 위젯으로 감싸고, 키보드의 '다음' 및 '완료' 액션을 처리할 수 있도록 구성.
-   [ ] Subtask: 비밀번호 필드에서 '완료'(엔터) 액션 시, `LoginViewModel`의 로그인 함수가 호출되도록 로직 연결.
-   [ ] Subtask: **(테스트)** 비밀번호 필드에서 '엔터'를 눌렀을 때 로그인 로직이 실행되는지 검증하는 위젯 테스트 추가.


**Task 3: 자동 로그인 기능 구현**

-   [ ] Subtask: 안전한 토큰 저장을 위해 `flutter_secure_storage` 패키지 추가.
-   [ ] Subtask: 토큰(accessToken, refreshToken)을 기기의 보안 저장소에 저장하고 불러오는 `TokenStorageService` 클래스 생성.
-   [ ] Subtask: `LoginViewModel`을 수정하여, 로그인 성공 시 `TokenStorageService`를 통해 토큰을 저장하도록 로직 추가.
-   [ ] Subtask: 앱 실행 시 로딩 및 라우팅을 담당할 `SplashScreen` 위젯 생성.
-   [ ] Subtask: `SplashScreen`에서 다음 로직을 수행:
    1.  보안 저장소에서 토큰을 비동기적으로 로드.
    2.  토큰이 존재하면, 유효성을 검증 (예: 프로필 정보 요청 API 호출).
    3.  유효성 검증 성공 시 -> **키워드 관리 화면 (미래 구현)** / 실패 시 -> **로그인 화면**으로 이동.
-   [ ] Subtask: `main.dart`의 `home`을 `SplashScreen`으로 변경.
-   [ ] Subtask: **(테스트)** `TokenStorageService`의 저장/읽기/삭제 기능에 대한 단위 테스트 작성.
-   [ ] Subtask: **(테스트)** `SplashScreen`의 조건부 라우팅 로직에 대한 위젯 테스트 작성.

**Task 4: 최종 검증**

-   [ ] Subtask: 전체 테스트(`flutter test`)를 실행하여 모든 기능이 정상 동작하는지 확인.
-   [ ] Subtask: 앱을 재시작했을 때, 자동 로그인이 정상적으로 동작하는지 시나리오 테스트 (수동).
