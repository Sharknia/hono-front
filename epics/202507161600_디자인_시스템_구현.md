### **Epic: 모던 디자인 시스템 구축 및 로그인 페이지 적용**

**목표:** 앱/웹 환경 모두에서 세련되고 일관된 사용자 경험을 제공하는 확장 가능한 디자인 시스템을 구축하고, 이를 로그인 페이지에 우선적으로 적용합니다.

**Task 1: 디자인 시스템 기반 정의**

-   [x] Subtask: 앱의 정체성을 나타내는 **색상 팔레트(Color Palette)** 정의 (Primary, Secondary, Background, Text 등).
-   [x] Subtask: 가독성과 일관성을 위한 **타이포그래피(Typography)** 시스템 정의 (Headings, Body, Button 등).
-   [x] Sub-task: 반응형 레이아웃을 위한 **간격(Spacing)** 및 **그리드(Grid)** 시스템 원칙 정의.
-   [x] Subtask: 정의된 색상과 타이포그래피를 `MaterialApp` 전체에 일관되게 적용할 `AppTheme` 파일(`lib/src/presentation/theme/app_theme.dart`) 생성.

**Task 2: 공용 위젯 컴포넌트 개발**

-   [x] Subtask: 디자인 시스템에 맞춘 재사용 가능한 **텍스트 입력 필드(`CustomTextField`)** 위젯 생성.
-   [x] Subtask: 다양한 상태(활성, 비활성, 로딩)를 지원하는 재사용 가능한 **버튼(`CustomButton`)** 위젯 생성.

**Task 3: 로그인 페이지 리디자인**

-   [ ] Subtask: `main.dart`에서 새로 정의한 `AppTheme`를 앱 전체에 적용.
-   [ ] Subtask: `LoginScreen`의 레이아웃을 재구성하여 중앙 정렬 및 반응형 디자인 적용.
-   [ ] Subtask: 기존 `TextField` 및 `ElevatedButton`을 새로 만든 `CustomTextField`와 `CustomButton`으로 교체.
-   [ ] Subtask: 로고나 환영 메시지를 추가할 공간을 마련하여 페이지의 시각적 완성도 향상.

**Task 4: 최종 검토 및 테스트**

-   [ ] Subtask: 다양한 화면 크기(모바일, 태블릿, 데스크탑 웹)에서 로그인 페이지의 레이아웃이 깨지지 않는지 확인.
-   [ ] Subtask: 리디자인된 로그인 페이지에 대한 위젯 테스트 코드 수정 및 실행.
